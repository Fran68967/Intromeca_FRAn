# Clase 1 — SolidWorks

Durante esta sesión adquirimos las bases para el modelado digital de piezas mecánicas utilizando SolidWorks, partiendo desde los conceptos básicos del dibujo bidimensional hasta la generación de sólidos tridimensionales con operaciones complejas.

## Selección del plano de referencia

El primer paso en cualquier proyecto de modelado 3D es establecer correctamente el plano de referencia sobre el cual se construirá el diseño. Esta decisión es crítica, ya que determina la orientación espacial de toda la pieza.

- **Planos disponibles:** SolidWorks proporciona tres planos principales (Alzado, Planta y Vista Lateral) que corresponden a las vistas ortográficas estándar en dibujo técnico.
- **Apertura del entorno de croquis:** Una vez definido el plano, se activa la herramienta Croquis, que permite trazar líneas, arcos y otras geometrías base.

## Restricciones y Cota inteligente

- **Restricción:** Son relaciones geométricas que fijan cómo se comportan las líneas: horizontal, vertical, tangente, coincidencia, etc.
- **Cota inteligente:** Da un tamaño específico a las líneas.

### Color del croquis

| Color | Significado |
|-------|-------------|
| Negro | Todo está definido (ideal para extruir) |
| Azul  | Faltan restricciones o cotas |

## Extruir

Convierte el perfil 2D en un sólido:

1. Operaciones → Saliente/Extruir
2. Asignar profundidad
3. Se genera el sólido 3D

### Modificar el modelo

- **Extruir corte:** Quitar el material de sobra.
- **Saliente/Extruir:** Añadir material en la misma figura.
