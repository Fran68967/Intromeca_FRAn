# Clase 3 — Ensambles

Los ensambles son la herramienta para unir piezas tridimensionales. Durante esta sesión aprendimos a duplicar piezas para unirlas y crear una caja.

![Caja ensamblada en SolidWorks](https://static.wixstatic.com/media/f6cf03_62968e79f8234ce68c445c8b5d338ab7~mv2.png)

## Pasos para ensamblar los componentes

1. Crear un archivo de Ensamble
2. Importar las piezas individuales
3. Aplicar relaciones de posición
4. Restringir los grados de libertad
